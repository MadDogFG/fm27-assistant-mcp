# FM26 / FM27 游戏底层机制与核心常识大全

本手册系统梳理 FM26/FM27 在**战术熟悉度与复杂度、团队与个人训练、青训造星与潜力开发、职员真实作用、更衣室动力学、伤病疲劳管理及联赛注册规则**上的底层机制，帮助 Agent 像资深老玩家一样避开常见隐形陷阱。

---

## 一、战术熟悉度（Familiarity）与战术复杂度（Complexity）

1. **战术熟悉度到底影响什么？**
   - 熟悉度拆分为阵型、心态、传球直接度、创意自由度、压迫强度、盯人、位置/角色/职责、攻防转换等维度。
   - **低熟悉度的真实惩罚**：球员在场上思考变慢、无球跑位犹豫、传球衔接出现莫名其妙的配合失误，导致“纸面战术很美，场上踢得像散沙”。
2. **如何最快拉满熟悉度？**
   - **善用 3 个战术槽位**：把主战术和微调变体（共享核心阵型与大部分指令）放进槽位，全队会同时训练这些槽位；
   - **季前赛多踢热身赛 + 战术/凝聚力合练**：比赛实战 + 战术课 + 赛前比赛准备课（Match Tactics / Match Practice）是涨熟悉度最快的途径；
   - **克制频繁大改**：确立主框架后至少给球队 4–6 场稳定磨合期，每次只微调 1–2 个局部原子，不要输一场就换全新阵型。
3. **战术复杂度（Complexity）的权衡**
   - 勾选指令越多、持球（IP）与无球（OOP）阵型变形幅度越大、角色越自由（如边中卫套上、伪边卫、自由组织核心），战术复杂度就越高。
   - **高复杂度的代价**：熟悉度增长明显变慢，且对全队 `决断(Decisions)`、`团队合作(Teamwork)`、`预判(Anticipation)` 要求极高。
   - **实战建议**：接手新队、弱队或低级别球队时，优先保持**简洁低/中复杂度**快速满熟悉度稳住下限；豪门或磨合到第二赛季时再逐步叠加精细机制。

## 二、团队训练与个人训练的底层机制

### 2.1 团队训练课的功能分工
- **常规专项课（进攻 / 防守 / 控球 / 技术 / 战术 / 体能）**：真正决定球员**长期属性成长**的核心课程；体能课（Quickness / Endurance / Resistance）对身体属性加成高，但能耗极大、最易引发肌肉伤病。
- **比赛准备课（Match Prep：赛前战术、进攻/防守演练、定位球演练）**：主要为**下一场比赛提供临时 Buff 与加速战术熟悉度**，对长期属性成长贡献小，但关键硬仗前极有价值。
- **恢复与休息（Recovery / Rest）**：`Recovery` 能在不完全停训的前提下显著降低疲劳与伤病风险；`Rest` 完全清空当日训练负荷。
- **团队凝聚力（Match Review / Team Bonding / Community Outreach）**：比赛回顾（Match Review）在赛后次日安排性价比极高，同步涨凝聚力与熟悉度；团建（Team Bonding）直接提升更衣室氛围与默契。

### 2.2 训练负荷、赛程密度与“体能 vs 疲劳”的致命区别
- **单赛周 vs 一周双赛**：
  - *单赛周*：可安排 2–3 节高强度技术/战术/轻体能课，兼顾成长与备战；
  - *一周双赛*：训练重点立刻转向 **恢复（Recovery）+ 比赛回顾 + 轻度战术/定位球**，严禁在两场比赛中间塞高强度体能课。
- **体能（Condition）≠ 隐性长期疲劳（Fatigue / Jadedness）**：
  - `体能`是单场消耗，睡 2–3 天就能回满；
  - `长期疲劳`是连续高强度出战数月累积的隐性透支——当队医提示某球员“需要休息 / 出现疲劳迹象”时，哪怕他赛前体能显示 95%，场上也会状态低迷且极易拉伤大修。**唯一根治办法是直接给 1–2 周假期休息（Rest）并轮休 1–2 场**。
- **比赛锐度（Match Sharpness）**：长期不踢球的替补锐度会跌，上场极易低级失误；应通过安排踢预备队/U21 或杯赛保持锐度。

### 2.3 个人训练（Individual Training）要点
- 每个球员同时受 **位置/角色训练 + 额外专项训练（Additional Focus）+ 球员习惯（Traits）** 共同影响（可通过 `get_individual_training` / `set_individual_training` 精细配置）。
- **双倍强度（Double Intensity）**：仅在球员体能充沛、职业素养高、赛程宽松且无伤病隐患时开启；疲劳或密集赛程期务必降回正常/半强度，否则直接练伤。
- **球员习惯（Traits）的隐形成本**：学习习惯会分走一部分个人训练时间，且某些习惯会覆盖你的战术指令（例如给后腰学了“有机会就前插”，哪怕你设了防守职责他也会乱跑）；**只给核心位置学真正契合打法的 1–2 个习惯，切忌盲目乱学**。

## 三、青训机制与“怎么把小将潜力（PA）真正练满”

### 3.1 CA / PA 与属性权重的核心真相
- 每名球员都有 **当前能力（CA）** 与 **潜力上限（PA）**。CA 随训练和比赛逐步向 PA 逼近，到达 PA 后总能力不再增长（但属性仍会随位置训练和年龄结构重新分配）。
- **属性权重不同**：不同位置的核心属性（如边锋的速度/爆发力、中锋的射门/无球、中卫的弹跳/盯人/防守站位）消耗的 CA 配额远高于边缘属性。
- **⚠️ 逆足与多位置会吃掉大量 CA 配额！** 练弱势脚（Weak Foot）或强行给小妖练 3–4 个不相关的新位置，会大幅吞噬宝贵的 CA 预算，导致他原本该涨到 17–18 的关键属性被摊薄到 14–15。**除非战术刚需，不要给满潜小妖乱加无关位置。**

### 3.2 青训日（Youth Intake）刷出顶级小妖的四大决定因素
1. **青训招募（Youth Recruitment）**：决定俱乐部挖来高 PA 天才的概率与地域覆盖范围（最关键的长期投资）；
2. **青训教练（Junior Coaching）**：决定小妖 15–16 岁刷出来时的**初始 CA 起点**；
3. **青训设施（Youth Facilities）**：决定青年队阶段日常训练的涨球效率；
4. **青训主管（Head of Youth Development, HOYD）**：他的**隐藏性格（职业素养/决心/雄心）和偏好阵型**，会直接影响每年青训日刷出小妖的性格分布与位置类型！宁可属性少 1–2 点，也要优先请**“模范公民 / 极具职业精神 / 模范职业”**性格的青训主管。

### 3.3 练满小将潜力的四阶段黄金路线图
1. **15–17 岁（打基础期：训练权重 >> 比赛）**
   - 留在拥有顶级训练设施和高星级教练的母队青年队安心涨球，**千万别过早外租到设施简陋的低级别球队**！
   - 个人训练优先补齐**身体/运动能力瓶颈**（速度、爆发力、耐力、强壮的成长窗口最早关闭，技术与精神可以慢慢涨）。
   - 若已具备一定实力，可提拔至一线队跟着顶级一线队教练训练（同时设为“可代表 U19/U21 出场”保证每周有球踢），并纳入好性格的导师小组。
2. **18–21 岁（爆发期：高质量比赛权重 >> 训练）**
   - **18 岁是 FM 成长的最大分水岭！** 18 岁之后如果只踢青年队或在一线队坐穿板凳，成长会断崖式停滞、PA 极易练废。
   - **两条出路**：要么在一线队给足每赛季 **20–30 场正式比赛（含替补登场 ≥ 20 分钟拿到赛后评分）**；要么果断挂牌外租（`PersonSetPlayersTransferStatus`），筛选租借下家时必须盯紧三要素：**① 训练设施至少“良好”以上；② 承诺“常规主力/重要球员”；③ 联赛声望与球员当前实力匹配（踢得上且能拿 ≥ 6.8 的高分）**。
3. **22–24 岁（定型冲刺期）**
   - 必须稳定踢高水平一线队主力，完成最后一段 CA 向 PA 的冲刺，并把个人训练转向**决断、镇定、预判、特定角色技术**等精细短板。24 岁后身体增长基本封顶，但精神属性在 27–30 岁仍会缓慢抬升。
4. **导师指导小组（Mentoring Group）的底层规则**（`get_mentoring_groups` / `manage_mentoring_group`）
   - 导师小组**不会直接涨技术/身体属性**，但能把高影响力资深球员的**性格（职业素养、决心、抗压、雄心）与球场习惯**传承给 21 岁以下、一线队影响力较低的小妖！
   - **黄金公式**：每组 3 人 = **1 名高更衣室层级 + 极佳性格（模范公民/极具职业精神/坚决）的老将** + **2 名同位置线且年龄 ≤ 21 岁的小妖**。
   - **⚠️ 毁妖红线**：严禁把性格“散漫 / 缺乏雄心 / 容易泄气 / 反复无常”的大牌球星放进导师小组，否则会把满潜小妖的职业素养彻底带歪，直接断送涨球速度！

## 四、职员（Staff）的真实作用与招聘关键属性

很多玩家只看职员的单项高分而忽略了底层算法，招人时按以下核心指标判断：

| 职员岗位 | 真正干的活（引擎机制） | 招聘核心属性（按优先级） |
|---|---|---|
| **助理教练（AssMan）** | 给出星级评估、战术/对手报告、代管训练与发布会 | `判断当前能力(JPA)` + `判断潜力(JPP)`（这两项低，他给你的星级和推荐首发全是不准的）+ `战术知识` + `人员管理` |
| **一线队/专项教练** | 直接决定各项训练星级与球员属性成长速度 | **专项属性**（进攻/防守/战术/技术/体能/门将）+ **通用三维（`决心 + 纪律要求 + 激励`）**；两者缺一不可！同时要确保每个训练类别的**负荷为“轻/平均”**，过载会直接掉星 |
| **青训主管（HOYD）** | 影响青训日刷出的小妖性格与位置倾向 | **好性格（第一优先级！）** + `判断潜力(JPP)` + `培养年轻球员` + `判断能力(JPA)` |
| **体育总监（DoF）** | 推荐引援目标、给出报价建议、代谈合同与清洗冗余 | `判断潜力(JPP)` + `判断能力(JPA)` + `谈判` |
| **球探（Scouts）** | 挖掘世界各地球员、生成报告与招募重点反馈 | `判断潜力(JPP)` + `判断能力(JPA)` + `适应力`（去陌生国家积累知识的速度） |
| **首席队医 / 队医（Physios）** | 加快伤后康复速度、提高伤情评估精准度 | `医疗(Physiotherapy)` |
| **运动科学家（Sports Scientists）** | **直接降低训练和比赛中的肌肉伤病发生率**，高压迫球队刚需 | `运动科学(Sports Science)`（高负荷球队务必配满名额！） |
| **表现/招募分析师** | 提供 Data Hub 比赛数据与球探统计图表 | `分析数据(Analysing Data)` |

## 五、更衣室动力学（Dynamics）与凝聚力

1. **三大晴雨表**（`get_squad_dynamics_and_hierarchy`、`get_squad_happiness_issues`）：
   - **球队凝聚力（Team Cohesion）**：直接决定场上传球路线默契与协防补位；**夏窗一次性大换血（同时首发 5–6 名新援）会让凝聚力暴跌**，即便纸面实力变强，前两个月也容易莫名其妙输弱队。解法是分批融入 + 多安排团队凝聚力与比赛回顾课。
   - **更衣室氛围（Club Atmosphere）**：受近期胜负、薪资满意度、承诺履行与更衣室矛盾驱动，氛围好时全队在场上的精神属性和逆境抗压明显更强。
   - **主教练支持度（Managerial Support）**：决定球员是否愿意为你拼命、以及出现矛盾时大部队站哪边。
2. **层级传染效应**：
   - 球队领袖（Team Leaders）与核心影响者（Highly Influential）的一句话能带动全队士气。对边缘替补可以强硬处理，对更衣室领袖务必谨慎沟通、提前兑现承诺。
3. **承诺与出场时间红线**：
   - 谈合同时**绝不给替补许诺“重要主力/核心球员”**，违约会直接引爆更衣室；
   - 许下任何承诺（如加强某位置、给青训机会、放人离队）前先确认自己能做到，做不到宁可拒绝谈判也不要空头支票。

## 六、联赛注册、外援与财政规则避坑

在不同联赛执教，买人前务必先查清当地硬规则，避免花大钱买来却报不上名：
- **西甲（La Liga）**：有严格的**工资帽限制**、一线队**强制解约金条款**、以及**最多注册 3 名非欧盟（Non-EU）球员**（南美球员在西班牙踢满 2 年可拿双国籍释放名额，买人前先看现有非欧占用数！）。
- **英超（Premier League）**：需要**劳工证（Work Permit）**，积分不够的小妖可用有限的 **ESC 特殊名额**或先外租刷积分；同时要求 25 人名单中至少 8 名本国青训（HGN）。
- **欧冠/欧联（UEFA 赛事）**：25 人 A 名单强制要求 **4 名本俱乐部青训（HGC，15–21 岁在队满 3 年）+ 8 名本国青训（HGN）**；这就是为什么豪门不仅要买 18 岁小妖，还要**在 18 岁生日前签下并在队留满 3 年**（或自产拉玛西亚/卡灵顿青训），否则欧冠报不满 25 人！
- **中超 / 中甲等亚洲联赛**：严查外援注册与同时出场名额上限，以及 U21/U23 本土出场政策，转会预算有限时优先把外援名额花在中轴线（强力中锋/进攻核/中卫）上。
- **财政公平（FFP）与卖人时机**：
  - 卖人最佳套现窗口是**合同还剩 2 年且刚打出一个高分赛季**；拖到只剩 1 年身价腰斩，剩半年会被免签白嫖；
  - 预算吃紧时善用**分期付款 + 出场/进球附加条款 + 下次转会分成**平滑当季现金流，同时注意分期会透支未来 2–3 年的转会预算。
