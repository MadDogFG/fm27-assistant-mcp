# FM26 / FM27 通用主教练决策指南（第一性原理）

本手册**不绑死任何特定阵型或固定套路**，而是建立一套通用的足球决策与 FM 引擎推理框架。Agent 面对任何联赛、任何强弱级别、任何人员结构的俱乐部时，都应按“**看人 → 搭结构 → 看数据归因 → 管体能与更衣室 → 经营引援**”的逻辑自主思考，真正玩懂游戏。

---

## 一、看人下菜碟：先审计手里的牌，再定打法

永远不要先拍脑袋定阵型再硬塞球员。开工前先用 `get_squad_snapshot` + `get_player_attributes` 回答 4 个问题：

1. **核心优势在哪里？** 队里最强的 3–4 名球员擅长什么位置和角色？战术设计必须让这批核心踢在最舒服的区域，而不是让他们去迁就体系。
2. **身体与运动能力处于联赛什么水位？**
   - FM 引擎中，**速度（Pace）、爆发力（Acceleration）、耐力（Stamina）、灵活（Agility）**决定了压迫覆盖范围、回追容错率和最后 20 分钟是否崩盘；
   - **弹跳（JumpingReach）与强壮（Strength）**决定了禁区防空、争一点球和定位球攻防下限。
3. **技术与心理短板是什么？**
   - 后场球员的**镇定（Composure）、传球（Passing）、视野（Vision）、决断（Decisions）**如果偏低，强行要求后场短传出球只会在本方禁区前不断送礼；
   - 中前场如果**无球跑动（OffTheBall）、预判（Anticipation）**不足，就不要设计过于复杂的多人穿插配合。
4. **阵容厚度与赛程密度如何？** 替补席深度不够时，高能耗打法在双赛周会直接引发伤病潮。

## 二、持球（IP）与无球（OOP）的通用空间平衡原理

FM26/FM27 把战术拆成**持球阶段（In Possession）**与**无球阶段（Out of Possession）**，排阵和选角色时用以下 4 条通用标尺检验是否合理：

1. **进攻空间覆盖（宽度 + 肋部 + 纵深）**：
   - 持球时，球场横向的**左右边路、左右肋部、中路**都要有人威胁；同时纵向既要有**回撤接应点**，也要有**冲击防线身后的纵深点**；
   - **反模式检查**：避免同一侧边锋与边后卫同时抱边或同时内收，导致两人位置重叠、另一片空间无人利用。
2. **剩余防守（Rest Defense）**：
   - 进攻展开时，必须确保本方中后场随时留有足够人手（通常 2–3 人）盯防对手留前的反击点，否则每次进攻被断就是对手单刀。
3. **无球防线与压迫的联动一致性**：
   - **防线高度 ↔ 遇敌线高度**：两条线之间距离不能拉得过大，否则中场会暴露出巨大空当被对手轻松转身打身后；
   - **防线高度 ↔ 中卫回追速度**：中卫转身慢、速度低时，防线前提必须谨慎；反之，防线退得过深（极低防线）会把禁区弧顶完全让给对手远射，需根据对手特点找平衡；
   - **压迫强度 ↔ 球队耐力与工作投入**：压迫不是越高越好，必须与全队体能、耐力和对手传控能力匹配。
4. **攻防转换简洁度**：
   - 持球站位与无球站位之间可以变形，但单名球员的回防/前插跨度不能超出其体能与速度极限，否则攻守转换瞬间必然漏人。
   - **克制过度微调**：确立核心逻辑后保持稳定，让全队积累战术熟悉度；每次只针对明确问题微调 1–2 项，不要每场大换血。

## 三、用数据做比赛诊断与复盘（因果归因，不凭感觉）

赛前先看 `get_pre_match_briefing` 与对手球探报告，赛中/赛后结合 `get_match_team_stats_and_xg`、`get_match_player_live_stats`、`get_datahub_analysis` 做因果排查：

| 场上现象 | 常见底层原因 | 调整思路 |
|---|---|---|
| **控球率高，但 xG 很低 / 射门全是远射** | 缺少纵深前插、宽度过窄或进攻节奏太慢，对手轻松落位摆大巴 | 提高节奏或增加前插跑动角色，拉开局部宽度或利用肋部直塞 |
| **xG 高但进不了球，反被对手几次反击打穿** | 剩余防守不足、边卫同时压上过多，或防线前提与中卫速度不匹配 | 留住一侧边卫或后腰兜底，检查失球区域针对性收紧转换防守 |
| **前 60 分钟势均力敌，70 分钟后连续丢球** | 压迫/节奏能耗超出阵容耐力上限，或换人/轮换不及时 | 赛前体能 <80% 提前轮换，赛中及时换下体能见底的中场/边路，适当降压迫 |
| **后场出球频频被断、送给对手高 xG 机会** | 对手高位逼抢强，且己方后场镇定/传球不足 | 放宽出球方式（不必死守短传），利用门将/长传直接越过对手第一道压迫线 |
| **对手某核心点反复制造威胁** | 针对性指令缺失或对应防守侧人员不足 | 查 `get_opposition_instructions` 结合对手属性做针对性逼抢/限制弱势脚 |

> 记住：**控球率不是胜负指标**。只要能持续制造比对手更高质量的射门机会（xG 差值为正）并限制对手绝佳机会，低控球同样是顶级踢法。

## 四、长周期经营：训练、轮换、更衣室与引援

1. **体能与锐度的动态平衡**：
   - **体能（Condition）**低 = 受伤与末段崩盘风险高 → 优先轮换、降训练强度或安排恢复课；
   - **锐度（Sharpness）**低 = 久疏战阵失误多 → 安排踢预备队/U20 或热身赛找回状态。
2. **训练与年轻球员培养**：
   - 团队训练负荷以轻度/平均为基线，密集赛程优先保恢复，避免训练伤病潮；
   - 个人训练根据位置和短板定焦点：年轻球员优先补足身体/运动能力瓶颈（技术可随比赛慢慢涨，身体黄金期有限）。
3. **更衣室与承诺管理（士气是隐形战力乘数）**：
   - **严守出场时间约定**：签约或续约时绝不轻易给替补许诺“核心/重要主力”，违约引发的不满会通过更衣室领袖层级迅速传染全队；
   - 士气持续走低时，及时关注收件箱预警、调整训练恢复并争取用一场稳健的胜利止血，避免陷入“连败 → 士气崩 → 更踢不过”的死亡螺旋。
4. **理性引援与薪资结构**：
   - 先审视**合同即将到期人员**与**冗余高薪替补**，清理薪资空间后再补强；
   - 有限预算优先解决**首发最弱一环**与**中轴线稳定性**；灵活结合免签、低薪租借与青训提拔，避免盲目透支工资预算导致董事会信任崩盘。
