# FM26 / FM27 高手主教练实战攻略（引擎 Meta 与赢球铁律）

本手册内化自 FM26 / FM27 新引擎（双阶段战术 + FM-Arena 实测属性权重 + 弱队防反与强队控球蓝图）的社区实战精华。**Agent 在帮玩家排阵、改战术、买人、定训练或救火保级前，必先对照本手册决策，严禁盲目乱调导致连败下课。**

---

## 一、FM26/FM27 核心机制：持球（IP）与无球（OOP）双阶段战术

FM26 起彻底取消传统职责（Duty）划分，将战术拆分为两套独立体系，**切忌让 IP 与 OOP 站位完全一致或跨度过大**：

1. **持球阵型（In Possession, IP）—— 制造局部人数优势**
   - **基础阵型推荐**：`4-2-3-1` 与 `4-3-3 DM Wide` 是全级别联赛最稳的底座，天然覆盖五条纵向进攻通道。
   - **不对称出球**：允许一侧边后卫内收组成“后场三中卫”保出球与防反击（Rest Defense），另一侧边后卫大胆前插套边。
   - **宽度与节奏**：FM26/FM27 引擎实测中，**略收窄进攻宽度 + 中高节奏**对破密集防守最有效（传球三角紧凑，迫使 AI 防线向中路收缩）。
   - **防反击底线（Rest Defense）**：进攻时后场至少保留 **2–3 名防守球员**（如 2 中卫 + 1 留守后腰/内收边卫），这是避免被 AI 打穿身后的铁律。

2. **无球阵型（Out of Possession, OOP）—— 瞬间落位紧凑防线**
   - 丢球瞬间自动切换成紧凑防守阵型（如持球 4-3-3 → 无球落回 **4-4-2** 或 **5-2-3 / 4-1-4-1**）。
   - 边锋在无球阶段应拉回中场线或选择具备回防职责的边路角色，防止对手边后卫套边形成 2 打 1。
   - **压迫强度必须匹配体能**：高位压迫（Higher LoE + Press Often）确实强，但若全队 `Stamina`（耐力）与 `WorkRate`（工作投入）偏低，强行 90 分钟高压会在 **70 分钟后体能崩盘、连丢绝杀球**。

## 二、强队控球 vs 弱队/中下游保级两套实战模板

### 模板 A：中下游 / 弱队防反保级（最怕乱压迫！）
> 典型反例：弱队无脑开“积极进取 + 极高压迫 + 后场短传”，结果场均被射爆、8 轮 1 分直接下课。

- **无球阵型**：`4-1-4-1`（单后腰扫荡中卫身前）或 `4-4-2`（双前锋留反击出球点）。
- **心态**：主场对同级用 **攻守平衡（4）**，客场或打强队用 **小心谨慎（3）** / **防守（2）**。
- **防线与压迫**：
  - 防线用 **标准（Standard）** 配合 **较低遇敌线（Lower LoE）**；**不要拉到“极低防线”**，否则会被压死在禁区里任人远射；
  - 压迫选 **减少压迫**，保持阵型紧凑不失位；**慎用紧逼盯人**（转身慢的弱队后卫一盯就被撞墙二过一过干净）。
- **攻防转换与进攻**：
  - 丢球后 **保持阵型（Hold Shape）**（不要盲目反抢）；断球后 **快速反击（Counter）** + 门将快速出球/大脚找前场支点；
  - 传球 **更直接（More Direct）** + **更高节奏（Higher Tempo）**；**关掉“后场短传出球”**（低镇定/低传球后卫强行短传必送大礼）；
  - 前锋配 **站桩中锋**（强壮/弹跳高）或 **突前前锋**（速度快打对方高防线身后，配合 `Pass Into Space`）。
- **心态预期**：弱队控球率 30%–40% 完全正常，只看 **xG 与绝佳机会**，不要因为控球低就胡乱改回传控。

### 模板 B：强队 / 争冠队主导控球
- **阵型**：IP `4-2-3-1` / `4-3-3`（边卫内收成 3-2-5），OOP 紧凑 `4-4-2` 中高位逼抢。
- **核心指令**：心态 **积极进取（5）**、略窄宽度、中高节奏、出球中卫（BPD）配同顺足节拍器（DLP），前场边锋/内锋冲击肋部（Half-spaces）。

## 三、引擎真实属性权重（FM-Arena 实测：选人与引援核心）

查球员属性（`get_player_attributes`）和排首发时，**不要只看 CA 星级**，按以下真实权重挑人：

1. **T0 统治级身体属性（最重要）**：
   - **`Pace`（速度）+ `Acceleration`（爆发力）+ `Stamina`（耐力）**：决定球员能否追上对手、过人摆脱及撑满 90 分钟，在 FM26/FM27 引擎中收益断层第一。
   - **`Agility`（灵活）**：在密集的中场狭小空间转身摆脱极强。
2. **T1 关键核心属性**：
   - **`JumpingReach`（弹跳）**：中卫与中锋超过 12 后制空优势巨大，直接决定定位球攻防失球率。
   - **`Anticipation`（预判）+ `Decisions`（决断）+ `Strength`（强壮）**：防止站桩发呆或对抗被碾压。
3. **引援与青训铁律**：
   - 优先买“**身体快/壮、技术稍糙**”的球员（技术好练、速度难涨）；
   - 预算紧张时优先查**合同剩 6 个月免签**与**低工资分担租借**；外援名额优先砸在**中轴线（中卫 / 后腰 / 锋霸）**。

## 四、训练、轮换与士气管理铁律（防止崩盘下课）

1. **训练最大化成长与防伤病**：
   - 团队训练负荷保持 **轻度 / 平均（Light / Average）**，密集赛程塞入 **恢复（Recovery）** 课；
   - 个人训练给年轻非门将球员优先设 **敏捷/速度（Quickness）**，门将设 **敏捷或扑救**；
   - **动态强度**：体能满格绿心开双倍强度，体能黄/红立刻降强度或休息（`set_team_training_intensity`）。
2. **轮换与体能底线**：
   - 赛前先调 `get_pre_match_briefing` 看预警：体能 `< 80%` 坚决轮换（否则最后 20 分钟必崩）；锐度 `< 60%` 安排踢预备队/U20 找状态。
3. **士气就是最强隐藏属性**：
   - **严守出场时间承诺**：别随便给替补签“重要主力”，一旦坐板凳士气雪崩会传染整个更衣室；
   - **不要过度微调（Don't Over-Tinker）**：保持 1–2 套核心战术熟练度拉满，不要每场大改 10 条指令导致全队战术熟悉度归零；
   - 连败或士气低迷时，季前/间歇期可约弱旅踢热身赛刷大胜拉回绿脸士气，并在训练高分（≥ 8.2）时多表扬球员。
