# FM26 / FM27 通用主教练高手教程（底层机理与流派适配指南）

本手册**绝不推销任何“万能阵型”或“唯一版本答案”**。足球与 FM 的魅力在于不同教练有不同的哲学——有人热爱极致传控、有人崇尚重金属高位压迫、有人擅长低位防反与定位球偷鸡、也有人喜欢两翼齐飞的传统英式冲击。

Agent 的核心职责是：**先理解玩家想踢什么足球 + 审计手头有什么牌 → 用底层引擎原理把玩家的思路落地成自洽的体系 → 在比赛中用数据诊断因果 → 用科学的训练、轮换、引援与青训让球队持续进化。**

> 战术深度拆解（每一条指令的**原子作用**、11 种可插拔**局部套路聚合**，以及 7 大现实足球哲学的**自由混搭原理**）见专项手册 [tactical-mastery.md](tactical-mastery.md)。

## 一、先懂人，再定阵：如何正确看懂一名球员与一套阵容

开工前先用 `get_squad_snapshot` + `get_player_attributes` 审计手头的牌，不要只看总评星级：

1. **星级（CA/PA）是“相对分”，不是绝对能力**
   - 球探/教练给的星级，是拿这名球员与**本队当前平均水平及所处联赛声望**对比打出的相对分。中甲 4.5 星大腿到了五大联赛可能只有 2.5 星；切尔西/巴萨的 3 星替补放到中游队就是绝对核心。
2. **三大类属性的底层分工**
   - **身体属性（决定打法上限与容错率）**：`速度(Pace)`、`爆发力(Acceleration)`、`灵活(Agility)`、`平衡(Balance)` 决定能否打高位防线、能否一对一过人与回追；`耐力(Stamina)` + `体质(NaturalFitness)` 决定能否支撑高节奏高压迫及一周双赛；`弹跳(JumpingReach)` + `强壮(Strength)` 决定禁区防空、高球争顶和定位球攻防下限。
   - **精神属性（决定稳定性与球商）**：`决断(Decisions)` 与 `预判(Anticipation)` 决定球员在场上选得对不对、动得早不早；`镇定(Composure)` 决定被逼抢或单刀时脚软不软；`无球跑动(OffTheBall)` 决定进攻找空当的能力；`防守站位(Positioning)` 决定无球补位；`集中(Concentration)` 决定会不会在 80 分钟后低级漏人；`工作投入(WorkRate)` 决定是否愿意执行压迫和回防。
   - **技术属性（决定执行精度）**：`停球(FirstTouch)`、`传球(Passing)`、`技术(Technique)`、`盘带(Dribbling)`、`射门(Finishing)`、`抢断(Tackling)` 等只有在精神与身体创造出空间/时间后才能稳定发挥。
   - **隐藏属性（性格决定上限与更衣室）**：`职业素养(Professionalism)` 决定训练涨球速度和自律性；`大赛发挥(ImportantMatches)` 决定关键战软不软；`稳定性(Consistency)` 决定状态波动；`抗压(Pressure)` 决定落后/客场时崩不崩。通过球员性格描述（如“模范公民 / 极具职业精神 / 坚决 / 雄心勃勃” vs “散漫 / 缺乏雄心”）和媒体评价即可判断。
3. **阵容审计四问（适配任何级别球队）**
   - 队里最强的 3–4 名核心是谁？他们最舒服的活动区域和脚下习惯是什么？
   - 后场（门将 + 中卫 + 后腰）的 `镇定 + 传球 + 视野` 够不够扛住对手高位逼抢？
   - 中卫的 `速度 + 爆发力 + 预判` 能不能支撑高位防线？边路球员是擅长抱边下底传中，还是擅长内切射门？
   - 替补席深度能否支撑高能耗打法？

## 二、彻底讲透战术引擎：心态、指令与它们之间的相互作用

FM 的战术面板不是一堆彼此孤立的开关，而是一个**强耦合的力学系统**。点亮一条指令前，必须清楚它会放大还是抵消其他指令。

### 2.1 心态（Mentality）：全队风险系数总开关
**误区**：以为“进攻心态 = 进攻强，防守心态 = 防守强”。
**真相**：心态本质上是**全队的风险偏好与纵深推进滑块**。当你调高心态时，游戏底层会**同时自动提高**：
- 传球冒险度（更敢直塞和长传）与进攻节奏；
- 持球时的前插人数、防线默认高度与压迫积极度；
- 降低拖延时间倾向。

**实战含义**：
- 哪怕阵型摆的是 5 后卫，用“积极/进攻”心态一样可以踢得极富侵略性；
- 哪怕阵型摆的是 4-2-3-1，用“谨慎/平衡”心态配合高精准短传，同样可以控球占优且极难被反击打穿；
- **不要把高心态和所有激进指令全部拉满叠加**（例如“全力进攻 + 极快节奏 + 极高防线 + 极高遇敌 + 极高压迫”），过度叠加会直接导致传球失误暴增、阵型脱节和 60 分钟全队体能崩盘。

### 2.2 持球指令（In Possession）的相互作用与冲突表

| 指令维度 | 底层作用 | 协同搭配（互相成就） | 常见冲突 / 反模式（互相打架） |
|---|---|---|---|
| **进攻宽度（Width）** | 决定持球时球员横向拉开的距离 | 破密集防守时适度拉宽，拉开对手防线间距；打短传渗透时适度收窄，缩短传球距离形成三角 | **极宽 + 极短传**：队友站得太远，短传根本够不到或容易被断 |
| **传球直接度（Passing Directness）** | 决定优先找近点安全传球，还是跳过中场直接找前场纵深 | 短传 + 适中/偏慢节奏 + 较窄宽度（控球渗透）；长传/直接 + 快节奏 + 前插前锋（防反/冲击） | **极短传 + 极快节奏**：除非全队停球/传球/决断都是顶级豪门水平，否则极快节奏下强求短传只会疯狂失误 |
| **进攻节奏（Tempo）** | 决定球员持球思考和出球的速度 | 破大巴或反击时提速打对手立足未稳；领先控场或技术粗糙时降速减少无谓丢球 | **极快节奏 + 拖延时间**：指令自相矛盾；**极慢节奏 + 缺乏创意**：对手轻松全员落位，射门全是远射 |
| **从后场组织（Play Out of Defence）** | 要求后卫/门将不轻易大脚解围，优先短传给后卫和后腰出球 | 门将脚下好 + 中卫镇定高 + 后腰回撤接应；配门将“短传给中卫/边卫” | 后场镇定/传球差却硬开此项，面对高压对手等于在自家禁区前不断送单刀 |
| **打入禁区（Work Ball Into Box）** | 压低远射和盲目传中频率，耐心寻找高 xG 机会 | 控球渗透、远射太多导致 xG 低时开启；搭配低/倒三角传中 | **打入禁区 + 尽早传中（Hit Early Crosses）**：一慢一快直接冲突；面对铁桶阵若缺少破局点，开此项可能全场倒脚不射门 |
| **传中类型（Low / Whipped / Floated）** | 决定边路起球方式 | 前锋矮快灵 → **低平球传中**；前锋高大强壮弹跳好 → **高球/弧线传中**；有后点包抄 → **混合/弧线** | 给 172cm 小快灵前锋配高球传中，或给 193cm 站桩中锋配低平球传中 |
| **边路套上/内切（Overlap / Underlap）** | 告诉持球边路“稍微等一拍，等边后卫从外线套上或内线肋部插上” | 边路内锋持球 + 进攻型边卫套边；会**略微降低边路节奏、提高边卫心态** | 反击打法慎用！等边卫套上那一拍会直接拖慢反击速度，让对手回防落位 |
| **自由发挥 vs 严守纪律** | 决定球员是否允许偏离预设指令去尝试高风险创意动作 | 队内核心视野/才华/决断极高时可开“自由发挥”破局 | 弱队或战术熟悉度低时开“自由发挥”，会导致阵型乱跑、传球失误失控 |

### 2.3 攻防转换指令（In Transition）的相互作用
1. **立刻反抢（Counter-Press） vs 保持阵型（Regroup）**：
   - **立刻反抢**：丢球瞬间周围 2–3 人立刻围抢，抢下来对手防线未落位就是绝佳机会；**代价**：极耗耐力，且一旦第一道反抢被对手一脚出球打穿，身后立刻大空档。适合体能好、中后场紧凑的球队。
   - **保持阵型**：丢球立刻回撤落位，守住禁区和肋部，极大节省体能、极难被打反击；适合打低位/中位防反、客场保平或体能吃紧时。
2. **快速反击（Counter） vs 稳住阵型（Hold Shape）**：
   - **快速反击**：断球瞬间前场立刻前插、持球人优先找身后直塞。注意：即使踢控球体系，也可以在对手压得很靠上时开“快速反击”，打不出来再自然转入阵地控球；
   - **稳住阵型**：断球后不急于向前冲，先回传/横传稳住控球权，适合比赛最后 15 分钟守胜果或极致传控。
3. **门将发球（Distribution）**：
   - 必须和你的进攻发起点匹配：打后场组织就给中卫/后腰/边卫；打快速反击就“快速发球 + 手抛/大脚找边锋或站桩中锋”；对手高位疯狂逼抢本方中卫时，果断改成**大脚找前场高点或边路空当**，直接跳过对手第一道压迫线。

### 2.4 无球指令（Out of Possession）的相互作用
1. **纵向紧凑度铁律（遇敌线 ↔ 防线高度）**：
   - **遇敌线（Line of Engagement）**决定前锋/前腰从哪里开始施压；**防线高度（Defensive Line）**决定后卫线站在哪里。
   - **双高（高遇敌 + 高防线）**：把战场压缩在对手半场，压迫极强，但要求中卫回追速度快、门将敢出击（清道夫门将）。
   - **双中（中位遇敌 + 标准防线）**：攻守最均衡，中场不脱节，适合绝大多数球队作为基准。
   - **双低（低遇敌 + 低防线）**：放弃中圈，死守禁区前沿，极省体能、不给身后球，但把禁区弧顶和远射空间让给了对手。
   - **⚠️ 致命反模式：高遇敌 + 低防线** → 前锋在对方禁区压迫、后卫缩在自家禁区，中场拉出 40 米巨大空当，对手一脚地面传递就能在中场无人区自由转身直面后卫线！
2. **压迫强度（Trigger Press）与协同项**：
   - 高压迫必须配合 **高工作投入 + 高耐力 + 较紧凑的线间距离**；
   - **阻止门将短传（Prevent Short GK Distribution）**：只有在你前场至少有 2–3 人高位站位时才有效，否则前锋白跑消耗体能；
   - **紧逼盯人（Tighter Marking）**：贴身跟防，适合限制技术好但速度一般的组织核心；**切忌**用来盯比你后卫快很多的爆点边锋/前锋，贴太紧一个假动作转身就被一步过！
   - **下脚凶狠（Get Stuck In） vs 保持站位（Stay On Feet）**：裁判尺度松、对手软弱/勇敢低时可上强度；本方吃牌多、禁区前沿任意球危险或对手盘带极强时改“保持站位”防送点球与红牌。
   - **逼向边路（Trap Outside） vs 逼向中路（Trap Inside）**：本方中卫防空极强但边路怕肋部渗透 → 逼向边路让对手传中；本方中路有强力双后腰绞肉机但怕对手高空传中轰炸 → 逼向中路封死边路传中。

## 三、适配玩家不同思路：六大主流足球哲学落地蓝图

当玩家告诉你“我想踢 XX 足球”时，不要强行把它改成别的阵型，而是用下面的底层框架帮他把**他的理念**踢到极致：

| 玩家想踢的足球哲学 | 核心赢球逻辑 | 关键人员门槛 | 典型指令协同思路 | 最怕什么对手 & 破局微调 |
|---|---|---|---|---|
| **1. 控球主导 / 阵地渗透（Tiki-Taka / 控制球权）** | 用高传球成功率掌控球权，通过三角短传和肋部穿插撕开铁桶阵，用控球代替防守 | 全队停球/传球/镇定/视野高；门将与中卫能出球；至少有 1–2 个无球前插纵深点 | 平衡/积极心态；较短传球 + 偏慢或标准节奏 + 适中/偏窄宽度；后场组织 + 打入禁区；丢球反抢 | **怕**：低位密集大巴（光控球没 xG）或极端高位疯抢。<br>**破局**：提一档节奏、增加前插攻击点、拉宽局部宽度或改低平球传中 |
| **2. 高位压迫 / 重金属足球（Gegenpress）** | 在对手半场制造混乱，抢下球 5 秒内完成致命一击，靠体能和转换速度碾压 | 全队高耐力/高工作投入/高侵略性；中卫回追速度够快；替补席厚度足 | 积极心态；标准/稍直接传球 + 快节奏；**丢球立刻反抢 + 快速反击**；双高防线/遇敌线 + 高压迫 + 阻止门将短传 | **怕**：长传直接打中卫身后 + 密集赛程体能崩盘。<br>**破局**：防线退一档或换快中卫；领先后 65 分钟降压迫、关反抢、早换边路与中场 |
| **3. 低位 / 中位快速防反（Direct / Fluid Counter）** | 主动让出球权引对手压上，靠严密阵型吸收压力，断球后 2–3 脚直打对手身后空当 | 中后场防空/站位/集中强；前场有至少 2 名速度/爆发力/无球跑动快的反击尖刀 | 谨慎/平衡心态；**直接传球 + 快节奏**；保持阵型落位 + **快速反击** + 门将快速发球；中/低遇敌 + 标准/低防线 | **怕**：对手也不压上（双方互等）或禁区外远射轰炸。<br>**破局**：遇弱队把心态和遇敌线提一档，增加后排插上人数 |
| **4. 边路爆破 / 两翼齐飞（Wing Play）** | 避开对手拥挤的中路，靠边锋+边卫二打一撕裂边路，大量高质量传中砸进禁区 | 边锋/边卫速度快、传中/盘带强；禁区内至少有 2 个抢点点（高大中锋 + 后点内锋/插上中场） | 较宽进攻宽度；两翼推进 + 传中类型严格匹配中锋身高；可配合套边（Overlap）形成边路人数优势 | **怕**：对手边路人盯人锁死或中卫双高塔全解围。<br>**破局**：增加肋部内切套上（Underlap）或倒三角低平球传中，打地面近门柱 |
| **5. 直接长传 / 力量冲击（Route One）** | 跳过技术对抗，直接高球找前场支点争一点、中前场快马抢二点，极致简洁高效 | 强力站桩中锋（弹跳/强壮/头球/平衡高）；周围配能前插抢二点的影锋/边锋 | 更直接传球 + 快节奏；门将大脚找支点；丢球迅速落位守住中路二点 | **怕**：对手中卫比我方中锋更高更壮，一点全丢。<br>**破局**：改打边路空当长传，利用中锋拉边错位欺负矮个边后卫 |
| **6. 务实防守 / 链式防守（Catenaccio / 摆大巴）** | 极致压缩禁区与肋部空间，靠纪律、防空、门将神扑和定位球/反击 1-0 赢球 | 门将门线强；中卫防空/站位/集中顶级；全队执行力高、有定位球高点 | 防守/谨慎心态；保持阵型落位；较低遇敌线 + 紧凑防线；利用拖延时间（领先后）+ 精雕定位球 | **怕**：开场早早先丢球被迫攻出来。<br>**破局**：提前准备一套“落后反扑”副战术槽（`get_tactic_slots` / `set_tactical_style` 一键切换） |

## 四、角色（Roles）、职责（Duties）与持球/无球（IP/OOP）空间平衡

不管选什么阵型，必须通过以下 4 条通用结构体检：

1. **三层职责梯度（防守 / 策应 / 进攻）**
   - 场上不能全是“进攻”职责（没人传球、丢球立刻被打穿），也不能全是“防守”职责（前锋孤立无援）。
   - 健康比例通常为：**3–4 个防守职责**（含门将与剩余防守基座）+ **3–4 个策应职责**（连接前后场、提供传球三角）+ **3–4 个进攻职责**（撕扯防线、终结进攻）。
2. **边路互补原则（杜绝同侧拥堵）**
   - 同一侧的边后卫与边锋**不要承担相同的横向空间任务**：
     - 如果边锋是内切型（内锋/内切边锋，往肋部和禁区钻），边后卫就该负责拉宽套边提供宽度；
     - 如果边锋是传统抱边下底传中，边后卫就可以内收保护中路（内切型边后卫）或留在后场兜底。
3. **中场三角分工（保护 + 调度 + 插上）**
   - 一个稳固的中场通常要同时覆盖三项职能：**防线身前扫荡/兜底（盾）**、**接应后卫向前出球（桥）**、**前插进禁区或肋部威胁（矛）**。如果两名中场同时前插、身后无人兜底，反击必炸。
4. **剩余防守（Rest Defense）与持球/无球变形成本**
   - 持球进攻压到对手半场时，本方中后场必须随时留有 **至少 2–3 名防守人** 看住对手留前的反击前锋（例如双中卫 + 1 名拖后后腰，或三中卫留后）；
   - FM27 的持球（IP）与无球（OOP）双阵型可以制造局部人数优势（如持球变 3-2-5、无球变 4-4-2），但**单名球员的变形跑动距离不能超过其速度与耐力极限**，否则由攻转守的那 3 秒必然漏出致命空当。

## 五、针对性指令（Opposition Instructions）与定位球博弈

### 5.1 针对性指令的精准用法（不要一键全勾！）
先看 `get_opposition_instructions` 与对手属性，只针对真正有威胁的 2–4 人下指令：
- **压迫（Trigger Press = Always）**：专治对手**后场出球手、拖后组织核心、镇定/传球偏低的门将或中卫**，逼迫他们仓促失误。
- **紧逼（Tight Marking = Always）**：专治对手**无球跑动好但速度/灵活一般的站桩前锋或静态前腰**；**切勿**对高速度高盘带的爆点边锋开紧逼，容易一步被过！
- **逼向弱势脚（Show Onto Weaker Foot）**：
  - 对顺足下底边锋 → 逼向内线（若我方中路拦截强）或逼向弱脚限制传中；
  - 对逆足内切射门型边锋 → **强制逼向弱势脚/外线**，不让他内切起左/右脚兜射！
- **凶狠铲抢（Tackling = Hard）**：只对**勇敢（Bravery）低、平衡差、容易受伤或心态脆弱**的核心使用，且我方对位防守人不能已背黄牌。

### 5.2 定位球（以弱胜强与破铁桶阵的免费红利）
- 强队破铁桶阵、弱队保级抢分，**30% 以上的进球来自角球、任意球和点球**。
- 用 `get_set_piece_takers` / `change_set_piece_takers`（默认读取进攻定位球 `setPieceScenario=1`）确保角球/任意球由脚法最好且不需要进禁区争顶的球员主罚，把全队**弹跳（JumpingReach）+ 头球（Heading）+ 勇敢（Bravery）**最高的 2–3 名大高个安排到近门柱/点球点/远门柱冲击，同时在弧顶留 1–2 名速度快的人防对手打定位球反击。

## 六、用实时数据做比赛诊断与临场调整（因果闭环）

赛前用 `get_pre_match_briefing` 快速对齐状态，赛中用 `get_match_team_stats_and_xg`（已直连直播 39 项实时统计：控球、射门/射正、xG、npxG、绝佳机会、PPDA 压迫强度、推进传球、进攻三区传球、角球、犯规、均分）+ `get_match_player_live_stats` 做精准因果诊断：

| 实时数据现象 | 核心底层原因 | 最小化精准调整（每次只改 1–2 项） |
|---|---|---|
| **控球率 >60%，但 xG 低、绝佳机会 = 0、远射多** | 进攻节奏过慢、缺乏禁区纵深跑动或宽度过窄，对手轻松落位 | 提一档节奏、开启“打入禁区”或把一名边锋/中场职责调为进攻增加前插 |
| **xG 领先且射门多，却被对手极少射门连续打穿** | 剩余防守不足、边卫同时压上过多，或高位防线遇上对手快马反击 | 留住一侧边卫或后腰改防守职责；防线降一档；对手快马关闭“紧逼” |
| **对手 PPDA 很低（<8）且我方后场传球成功率骤降** | 对手正在疯狂高位逼抢，我方后场短传出球扛不住 | 关闭“从后场组织”，门将改为大脚找高点/边路空当，或拉宽传球直接度跳过压迫 |
| **我方 PPDA 很高（>18）却想踢压迫，对手轻松推进三区** | 遇敌线与防线脱节、压迫强度不够或前场球员工作投入/体能见底 | 收紧两条线距离，换上体能充沛的前场压迫点，针对对手后场组织核开压迫 |
| **前 60 分钟占优，70 分钟后评分下滑、频频失误丢球** | 高压/快节奏透支体能，未及时换人控场 | 60–70 分钟优先换下体能 <70% 的边路与中场；领先时降压迫/降节奏/关反抢改稳守 |
| **某一名球员评分 <6.4 且传球/抢断数据极差** | 被对手针对性克制、位置不熟或心态紧张 | 先看其体能与黄牌，及时调整对位职责、降低冒险指令或果断对位换人 |

> **关键心法**：确立一套战术逻辑后要给球队时间积累**战术熟悉度**。不要因为输了一场 xG 占优的“运气球”就推倒重来；每次复盘只修正数据明确指向的那 1–2 个短板。

## 七、长周期俱乐部经营：青训培养、引援策略与更衣室管理

### 7.1 青训与小妖培养的底层引擎规律
1. **18 岁分水岭法则**：
   - **18 岁之前**：**训练设施 + 教练星级 + 职业素养** 对成长权重最大，留在拥有顶级青训设施的母队青年队系统训练，往往比外租去设施简陋的低级别球队涨得更快；
   - **18 岁之后**：**高质量一线队比赛时间（评分 ≥ 6.8）** 成为成长核心引擎！18–21 岁如果在一线队坐穿板凳，PA 极容易烂掉——要么给足杯赛/轮换首发，要么外租到**设施良好 + 承诺主力位置 + 联赛水平匹配**的球队（可用 `PersonSetPlayersTransferStatus` 挂牌可租借）。
2. **个人训练黄金期**（`get_individual_training` / `set_individual_training`）：
   - 年轻球员优先打磨**身体/运动能力瓶颈**（速度/爆发/耐力/强壮的成长窗口最早关闭），同时尽早确定长期目标位置角色，避免反复横跳浪费 CA 配额；
   - 注意把控训练负荷，体能偏低时适当降强度或安排休息，防止大伤永久折损 PA。
3. **导师指导小组（Mentoring Group）的正确用法**（`get_mentoring_groups` / `manage_mentoring_group`）：
   - 导师小组的核心作用是**把高职业素养、高决心、高抗压、好性格的资深老将（高更衣室层级）的心态与球场习惯传递给 21 岁以下小妖**；
   - **绝对禁忌**：千万别把“散漫 / 缺乏雄心 / 低职业素养”的老将和大牌放进导师小组，否则会把满潜小妖带歪！每组保持 3 人（1 名模范领袖 + 2 名同位置线小妖）效果最稳。

### 7.2 理性引援、卖人与薪资结构
1. **精准找人双通道**：
   - 已有明确目标姓名（如搜索球探或现实中看中的小妖）→ 直接用 `search_players({ name })` 毫秒级全库直达；
   - 按位置/年龄/免签/身高缺口海选 → 用 `search_players({ position, maxAge, freeAgentOnly, sortBy })` 配合球探招募重点（`get_recruitment_focuses` / `complete_recruitment_focus_draft`）持续挖掘。
2. **买人卖人时机**：
   - 优先审视队内**合同仅剩 1–2 年**的球员：核心立刻续约防被免签挖角，冗余老将/高薪替补果断在合同还剩 2 年时挂牌套现（`PersonSetPlayersTransferStatus` + `get_transfer_activity`），不要拖到最后半年烂在手里；
   - 报价时既可采纳体育总监建议快速成交，也可用 `stage_transfer_clause({ kind: "cash", amount })` 精确控制现金支出，并用分期/出场附加条款平滑当季转会预算。
3. **更衣室与承诺红线（士气是隐形战力乘数）**：
   - **绝不乱许诺出场时间**：给替补许诺“重要主力”必引发更衣室暴雷，且会通过更衣室领袖层级迅速传染全队；
   - 严守训练恢复与轮换纪律：体能（Condition）低易伤、锐度（Sharpness）低易失误；密集赛程主动轮换主力、让替补踢杯赛/预备队保持锐度，确保全季状态曲线平稳向上。
