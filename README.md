# FM27 Assistant

*Football Manager 27* 的实时 AI 助教插件。

装好之后，你可以直接用 Claude、Cursor、Windsurf、Antigravity 等 AI 客户端连接正在运行的 FM27 存档——让 AI 看懂你现在的球队情况，帮你出主意，也可以直接替你点好战术、安排训练、起草报价和处理日常事务。

它只通过游戏自带的正常操作接口工作，**不修改存档文件，不篡改球员数值或资金，也不是外挂修改器**。

---

## 它能做什么

连上游戏存档后，你可以像跟助理教练对话一样下达指令：

- **阵容管理与排兵布阵**  
  一键做全队体检（哪些位置缺人、哪里人满为患、哪些高薪老将该清理），结合体能、伤停和位置熟练度算出最优首发 11 人和替补席，也可以直接帮你排好阵型与首发。

- **战术与定位球设置**  
  查看并调整阵型、心态、团队/球员指令、预设战术风格、战术槽位以及赛前针对性防守指令，查看并调整定位球主罚人选。

- **训练与青训培养**  
  查看并修改球队周训练日程、单人位置训练和训练强度，安排导师小组，检查疲劳过高的主力并安排休息。

- **球探招募与转会谈判**  
  按名字或条件检索球员、查看球探报告与候选名单、新建招募重点、发起或修改转会/租借报价、处理本队球员续约。

- **比赛数据与赛后复盘**  
  实时或赛后读取控球率、射门、xG、传球与压迫数据，帮你复盘战术问题并给出调整建议。

- **俱乐部日常事务**  
  读取并整理收件箱、调整转会与工资预算分配、管理球员注册与球衣号码、向董事会提诉求、推进游戏日期。

### 日常对话示例

> “看看下周对手和我们队里目前的伤病体能，帮我算一套最强首发 11 人。”  
> “帮我做一次全队阵容和合同体检，标出缺人的位置和值得清洗的高薪球员。”  
> “把下一周赛前一天的训练改成定位球和团队凝聚力，体能低于 75% 的主力安排休息。”  
> “查一下 20 岁以下有潜力的中场，整理一份推荐名单。”  
> “看看上一场比赛的 xG 和进攻数据，分析为什么我们控球高却进不了球。”

## 安全与使用边界

默认以“助教模式”运行，避免 AI 替你做不可挽回的决定：

- **比赛期间只看不改**：可以实时看数据、问建议，默认不自动临场换人或改战术。
- **不代答发布会与谈话**：新闻发布会、更衣室谈话与球员互动留给你自己掌控。
- **外部新援最终签约留给你**：本队续约和转会报价确认后可直接提交，外部球员新签合同的最后一步保留在游戏内完成。
- **仅限本机访问**：插件只在本地 `127.0.0.1` 监听并自动启用随机密钥校验，不上传任何存档数据。

各项功能的详细支持与实测情况可查看 [功能支持清单](docs/CAPABILITIES.md)。

## 快速安装

更详细的图文与排障步骤见 [完整安装指南](docs/install-guide.md)。

### 1. 准备环境

- PC 版 *Football Manager 27*
- [BepInEx 6 (Unity.IL2CPP win-x64)](https://builds.bepinex.dev/projects/bepinex_be)
- [Node.js 20+](https://nodejs.org/)

### 2. 安装游戏内插件

1. 将 BepInEx 6 解压到 FM27 游戏根目录，**启动一次游戏到主菜单后退出**（让它自动生成 `BepInEx\interop` 目录）。
2. 将本仓库中的 `dist/FMAssistant.dll` 复制到：
   ```text
   <FM27游戏根目录>\BepInEx\plugins\FMAssistant\FMAssistant.dll
   ```

### 3. 接入你的 AI 客户端

- **Antigravity 等支持插件目录的客户端**：直接加载本仓库文件夹即可自动启用。
- **Claude Desktop / Cursor / Windsurf 等 MCP 客户端**：在 MCP 配置中添加以下内容（无需 `npm install`）：

```json
{
  "mcpServers": {
    "fm27-assistant": {
      "command": "node",
      "args": ["<本仓库绝对路径>/mcp/fm-assistant-mcp.mjs"],
      "env": {
        "FM_ASSISTANT_URL": "http://127.0.0.1:27190"
      }
    }
  }
}
```

### 4. 开始使用

启动 *Football Manager 27* 并载入你的存档，在 AI 对话里输入一句“检查一下 FM27 插件连接”，确认连接正常后就可以直接开始聊战术和管球队了。

## 遇到问题怎么反馈

如果使用中报错或卡住，可以把下面两份本地日志附在 Issue 里，方便快速定位：

- **MCP 侧日志**：`<本仓库目录>/logs/mcp.log`
- **游戏侧日志**：`<FM27游戏根目录>/BepInEx/plugins/FMAssistant/state/live.log` 与 `BepInEx/LogOutput.log`
